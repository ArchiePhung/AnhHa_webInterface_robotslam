2. Configure Apache for Remote Access

Edit the Apache configuration file for phpMyAdmin. Usually located at /etc/apache2/conf-available/phpmyadmin.conf:

sudo nano /etc/apache2/conf-available/phpmyadmin.conf

Locate the <Directory /usr/share/phpmyadmin> block and ensure it looks like this:

<Directory /usr/share/phpmyadmin>
    Options FollowSymLinks
    DirectoryIndex index.php

    <IfModule mod_php.c>
        php_value include_path ".:/usr/share/php"
    </IfModule>

    Require all granted
</Directory>

The key line here is Require all granted, which allows access from any IP address.

Save the file and restart Apache:

sudo systemctl restart apache2

To set up phpMyAdmin with access via an IP address, follow these steps:
1. Install Required Software

Ensure you have the necessary software installed:

    A web server (e.g., Apache or Nginx).
    PHP.
    MySQL or MariaDB.
    phpMyAdmin.

Example on Ubuntu:

 >> sudo apt update
 >> sudo apt install apache2 php mysql-server phpmyadmin

During installation, configure phpMyAdmin to work with your web server (e.g., Apache) and set up the database root password.
2. Configure Apache for Remote Access

Edit the Apache configuration file for phpMyAdmin. Usually located at /etc/apache2/conf-available/phpmyadmin.conf:

 >> sudo nano /etc/apache2/conf-available/phpmyadmin.conf

Locate the <Directory /usr/share/phpmyadmin> block and ensure it looks like this:

    <Directory /usr/share/phpmyadmin>
        Options FollowSymLinks
        DirectoryIndex index.php

        <IfModule mod_php.c>
            php_value include_path ".:/usr/share/php"
        </IfModule>

        Require all granted
    </Directory>

The key line here is Require all granted, which allows access from any IP address.

Save the file and restart Apache:

    >> sudo systemctl restart apache2

3. Allow Remote Access to MySQL

By default, MySQL listens only on localhost. You need to configure it to allow access from other IP addresses:

Edit MySQL Configuration:

 >> sudo nano /etc/mysql/mysql.conf.d/mysqld.cnf

Find the line:

 >> bind-address = 127.0.0.1

Change it to:

 >> bind-address = 0.0.0.0

Save and close the file.

Grant Remote Access to a User: Log in to MySQL:

 >> sudo mysql -u root -p

Run the following command to allow a specific user (e.g., root) to connect from any IP:

 >> GRANT ALL PRIVILEGES ON *.* TO 'phpmyadmin'@'%' IDENTIFIED BY '000';
 >> FLUSH PRIVILEGES;

If cannot grant priviledges, do below:
    Create or Update the User Use CREATE USER if the user does not exist, or ALTER USER if it already exists:

    >> CREATE USER 'phpmyadmin'@'%' IDENTIFIED BY '123';

    If the user already exists, update the password:

    >> ALTER USER 'phpmyadmin'@'%' IDENTIFIED BY '123';

    Grant Privileges After creating or updating the user, grant all privileges:

    >> GRANT ALL PRIVILEGES ON *.* TO 'phpmyadmin'@'%';

    Apply Changes Always run FLUSH PRIVILEGES to ensure changes take effect:

    >> FLUSH PRIVILEGES;

Restart MySQL:

  >> sudo systemctl restart mysql

If you get error: ER_NOT_SUPPORTED_AUTH_MODE: Client does not support authentication protocol requested by server; consider upgrading MySQL client

Fix this: 
    >> sudo mysql -u root -p
    >> ALTER USER 'phpmyadmin'@'%' IDENTIFIED WITH mysql_native_password BY '123';
    >> FLUSH PRIVILEGES;
    >> sudo systemctl restart mysql
